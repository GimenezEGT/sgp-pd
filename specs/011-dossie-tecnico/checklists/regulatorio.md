# Regulatório (RDC 830/2023, art. 58 e Anexo II) Checklist: Dossiê técnico para a ANVISA

**Purpose**: Avaliar se os requisitos cobrem o conteúdo e a forma do dossiê exigidos para notificação ou registro (revisão de requisitos, não de código)
**Created**: 2026-11-11
**Feature**: [spec.md](../spec.md)

**Review Ownership**: This checklist is a reviewer-owned requirements-quality review artifact. Mark an item `[x]` only when the reviewer determines the requirements-quality criterion is satisfied.

Profundidade: padrão. Público: Assuntos Regulatórios e Garantia da Qualidade.

- [ ] CHK001 Os itens I a XII cobrem todos os incisos do art. 58 (descrição, imagens, risco, normas, certificado, desempenho, estabilidade, desempenho clínico, rotulagem, fabricação)? [Coverage, Spec §FR-001, docs/contexto/04-requisitos-regulatorios.md]
- [ ] CHK002 A aplicabilidade por classe (Anexo II) está definida para cada item e é ajustável sem programação? [Completeness, Spec §FR-001, §FR-002]
- [ ] CHK003 A estabilidade com pelo menos três lotes (art. 58, VII) está prevista na checagem ou registrada como pendência? [Gap, docs/contexto/04-requisitos-regulatorios.md]
- [ ] CHK004 Itens não aplicáveis exigem justificativa rastreável até a origem? [Completeness, Spec §FR-003]
- [ ] CHK005 A declaração do responsável técnico e legal (art. 56) usa o texto vigente e identifica a forma de assinatura? [Clarity, Spec §FR-007, §Clarifications]
- [ ] CHK006 A conferência da estrutura contra o Manual de Regularização de IVD (ANVISA, 25/08/2026) está registrada como pendência antes do primeiro envio? [Assumption, Spec §Clarifications]
- [ ] CHK007 O dossiê de classe I fica arquivado e disponível para inspeção, sem envio (art. 57, §1º)? [Completeness, Spec §FR-011]
- [ ] CHK008 O aditamento mostra todas as mudanças desde a última versão enviada e só elas? [Measurability, Spec §FR-012, SC-002]
