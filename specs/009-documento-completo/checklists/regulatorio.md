# Regulatório (registro histórico do projeto, RDC 665/2022 art. 61) Checklist: Documento completo do projeto

**Purpose**: Avaliar se os requisitos garantem um registro histórico do projeto completo, íntegro e consultável (revisão de requisitos, não de código)
**Created**: 2026-11-11
**Feature**: [spec.md](../spec.md)

**Review Ownership**: This checklist is a reviewer-owned requirements-quality review artifact. Mark an item `[x]` only when the reviewer determines the requirements-quality criterion is satisfied.

Profundidade: padrão. Público: Garantia da Qualidade e Assuntos Regulatórios.

- [ ] CHK001 As partes exigidas para o registro histórico (planejamento, entradas, saídas, verificação, revisões, validação, alterações e transferência) estão todas cobertas pela ordem definida? [Coverage, Spec §FR-003, docs/contexto/04-requisitos-regulatorios.md]
- [ ] CHK002 Está claro que só versões aprovadas entram no corpo e que as substituídas ficam no quadro de versões? [Clarity, Spec §FR-004, §FR-010]
- [ ] CHK003 O quadro de versões identifica signatários, significado e data de cada aprovação? [Completeness, Spec §FR-008]
- [ ] CHK004 O resumo da trilha tem formato definido e suficiente para inspeção, com acesso à trilha completa? [Clarity, Spec §FR-009, §Clarifications]
- [ ] CHK005 O critério para o documento sair oficial (sem pendências) e o tratamento do rascunho estão definidos sem ambiguidade? [Clarity, Spec §FR-012, §FR-013]
- [ ] CHK006 O documento arquivado tem resumo criptográfico, versão e código de verificação, e nunca é alterado? [Completeness, Spec §FR-014]
- [ ] CHK007 O histórico do caderno (completo ou resumido) preserva a atribuição, as assinaturas e os adendos das entradas? [Completeness, Spec §FR-007]
- [ ] CHK008 A restrição dos dados financeiros não compromete a integridade do registro (o que foi omitido fica identificado)? [Consistency, Spec §FR-005]
- [ ] CHK009 A ordem oficial das partes está registrada como pendente de ratificação, com a variante observada no projeto DBS? [Assumption, Spec §Clarifications]
- [ ] CHK010 A retenção do documento completo pelo tempo de vida do produto (art. 37) está prevista ou remetida à política de backup? [Gap]
