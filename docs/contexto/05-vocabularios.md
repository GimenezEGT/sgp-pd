## Tipos de estudo (proposta — aprovar com a Qualidade)

Cada tipo é definido pelo fator que varia, para que cada estudo tenha um nome único.

| Tipo | Fator que varia | Saídas calculadas |
| --- | --- | --- |
| Comparação de métodos (exatidão) | Kit em teste × kit de referência | Diferença média, DP das diferenças, concordância, correlação |
| Repetibilidade | Replicatas na mesma corrida e no mesmo dia | Média, DP, CV% |
| Reprodutibilidade entre dias | Dias diferentes | Média, DP, CV% por dia e global |
| Entre lotes | Lotes diferentes | Média, DP, CV% por lote e global |
| Sensibilidade analítica / limite de detecção | Diluições de concentração conhecida | Menor concentração detectada |
| Interferentes | Substância e concentração | Esperado × encontrado, desvio |
| Reatividade cruzada | Organismos ou alvos não pretendidos | Detecção sim/não |
| Efeito prozona de alta dose | Concentrações altas | Detecção sim/não |
| Linearidade / faixa de medição | Pontos de concentração | Regressão, R², faixa linear |
| Cut-off | Painel positivo/negativo | Valor de corte e interpretação |
| Sensibilidade e especificidade clínicas | Amostras caracterizadas | Proporções com IC 95% (Clopper-Pearson) |
| Valor esperado / de referência | População | Distribuição e valor de referência |
| Estabilidade de longa duração | Tempo nas condições de armazenamento | Regressão, R² por ponto |
| Estabilidade acelerada / transporte | Estresse de temperatura e tempo | Comparação com teste inicial |
| Estabilidade após aberto / on board | Tempo após abertura | Comparação com teste inicial |
| Validação externa | Laboratório parceiro | Resultado e conclusão do parceiro |
